# Cozy apartments, old town

Сайт квартиры в Вильнюсе. Русская и английская версии, галерея из 13 фотографий, удобства, расположение и переход к бронированию на Airbnb.

## Публикация на GitHub Pages

1. Создайте публичный репозиторий `cozy-apartments`.
2. Загрузите содержимое этого архива в корень ветки `main`: файл `index.html` должен находиться рядом с `app.js`, `styles.css` и папкой `assets`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Source → Deploy from a branch**.
5. Выберите ветку **main**, папку **/(root)** и нажмите **Save**.
6. Дождитесь публикации и откройте **Visit site** в разделе Pages.

Сайт не требует установки библиотек или сборки. Пути к фотографиям и стилям адаптированы для адреса с названием репозитория. Файл `.nojekyll` отключает обработку Jekyll.

Официальная инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Бронирование

Кнопки ведут на объявление https://www.airbnb.com/rooms/1752366128630309756 без заранее заданных дат.

## Изменения

- `index.html`: текст и структура.
- `styles.css`: оформление.
- `app.js`: английский перевод, меню и галерея.
- `assets/`: фотографии и значок сайта.

Фотографии предоставлены владельцем. Лицензия на свободное использование фотографий не предоставляется.
